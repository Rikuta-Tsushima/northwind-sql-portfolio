# Northwind SQL Portfolio

このリポジトリは、サンプルデータベース **Northwind** を用いたSQLポートフォリオです。  
基本的な集計や分析を行い、スキルを身につけることを目的としています。

---

## 📝 主な内容（Step1〜8）

1. **分析用ビューの作成**  
   注文明細を集計しやすい形に整備したビューを作成。  
   → 以降の全クエリはこのビューを土台に展開。

2. **売上トレンドの可視化**  
   月別売上を算出し、3ヶ月移動平均を計算。  
   → 季節性や中長期的な傾向を把握できる。

3. **従業員ごとの売上ランキング**  
   全期間・月別の両面から社員別の売上を比較。  
   → 成績上位の従業員や時期ごとの変動を把握。

4. **RFM分析（Recency）**  
   「最近購入した顧客ほど優良」と仮定し、購入からの経過日数を分位で評価。  
   → ロイヤル顧客の抽出の基礎指標を作成。

5. **リピート率の算出**  
   初回購入後、再度注文した顧客の割合を集計。  
   → 顧客の定着度を測る指標として活用可能。

6. **サプライヤ別・商品別売上TOP3**  
   各サプライヤごとに売上上位3商品を抽出。  
   → 強みとなる商品群を明確化。

7. **カテゴリ別の利益率比較**  
   割引後売上 ÷ 割引前売上を算出し、カテゴリごとに比較。  
   → 値が高いカテゴリほど割引依存が少なく利益率が高いと解釈。

8. **配送国別の売上分析**  
   配送先の国ごとに、売上・注文数・ユニーク顧客数を集計。  
   → 国別の主要マーケットを特定。
  - 顧客のリピート率分析
